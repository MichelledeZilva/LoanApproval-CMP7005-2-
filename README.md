Loan Approval Prediction System
---------------------------------------
This project develops a machine learning-based Loan Approval Prediction System using applicant, financial, credit, employment, and loan-related information.

The project includes data pre-processing, exploratory data analysis, feature engineering, machine learning model development, model evaluation, and a graphical user interface (GUI) for loan approval prediction.

 Project Objective
---------------------------------------

The main objective of this project is to develop machine learning models that can predict whether a loan application is likely to be approved or not approved.

The final application allows a user to:

- Enter applicant and loan information
- Select a machine learning model
- Generate a loan approval prediction
- View the approval probability
- Explore information about the dataset
- Perform basic exploratory data analysis

 Dataset
---------------------------------------

The project uses two loan approval datasets:

- `Loan_Approval_Data_Set_1.csv`
- `Loan_Approval_Data_Set_2.csv`

The datasets were combined to create the final merged dataset:

-merged_df.csv

The final dataset contains 20,000 records and includes applicant, financial, credit, employment, and loan-related variables.

The target variable is:
LoanApproved
